# Chick-fil-A (chickfila)
Chick-fil-A is an American fast-food restaurant chain specializing in chicken sandwiches and operating over 3,000 locations across the United States. Known for customer service and a closed-on-Sunday policy, Chick-fil-A operates the Chick-fil-A One tiered loyalty program, the Chick-fil-A mobile app for ordering and rewards, the catering platform, and eGift Cards.

### Chick-fil-A BOVINE
BOVI(n)E (Building Operational Visibility Into (n) Environments) is a serverless, open-source AWS multi-account governance dashboard published by Chick-fil-A. Built on AWS Lambda, API Gateway, DynamoDB, S3, and an AngularJS front end with Cognito auth, it provides a single-pane view of accounts, IAM users and roles, EC2 instances, public IPs, security groups, load balancers, databases, S3 buckets, and compliance audit reports. This is the only Chick-fil-A repository exposing a documented HTTP API surface; the company operates no public consumer developer API.

**Human URL:** [https://github.com/chick-fil-a/bovine](https://github.com/chick-fil-a/bovine)
